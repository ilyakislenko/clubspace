## Сделано ночью 2026-11-08 (без участия владельца)
- Двухфакторная защита (TOTP) для админов платформы: без кода из приложения-аутентификатора
  права суперадмина не действуют (`PLATFORM_ADMIN_MFA_REQUIRED`, в проде включено). Подключение —
  `/platform/security` в админке; второй шаг входа есть в админке, на сайте и в приложении;
  один код нельзя использовать дважды. Перед первым деплоем каждый админ платформы
  подключает аутентификатор (см. `deploy/README.md`).
- Отчёты о сбоях: мобильное приложение ловит ошибки (экран «Что-то пошло не так» + глобальный
  обработчик) и шлёт их на свой сервер `POST /client-errors` → лог + Sentry (если задан DSN).
  Данные остаются на нашем сервере. Страницы ошибок в admin и на сайте.
- Sentry: `release` = короткий sha деплоя; браузерный DSN теперь можно включить в проде.
- Экспорт персональных данных (ст. 14 152-ФЗ) включает заметки, закладки, планы, разборы.
- Разборы видео учеников видят только сам ученик, владелец/админ/главный тренер и тренеры его групп.
- Закладки и заметки нельзя привязать к закрытому уроку.
- Вход: блокировка аккаунта больше не позволяет злоумышленнику запереть владельца
  (мягкая блокировка — только для адресов, с которых подбирали код; жёсткая — при 50 ошибках).
- Код отметки на тренировке — криптостойкий; websocket принимает только свои домены;
  «Пересоздать субтитры» — не чаще 10 раз в час.
- Импорт клуба из Excel (.xlsx), а не только CSV — как обещает лендинг.
- Чек-лист запуска клуба: добавлены «Создайте абонемент» и «Подключите оплату».
- Закрытая регистрация ведёт на форму заявки и почту поддержки; в приложении — подсказка
  владельцу, что клуб создаётся на сайте.
- Юр. тексты: политика больше не утверждает, что заметки хранятся только на устройстве;
  описаны разборы, автосубтитры, отчёты о сбоях, ИИ-ассистент (помечено `NOTE FOR LAUNCH`).
  Условия берут оператора и почту из env, а не из кода.
- Лендинг: в подвале контакты, оферта, ДПД, согласие, реквизиты; Яндекс Метрика и
  подтверждение сайта для поисковиков включаются через env; фраза «серверы в России»
  показывается только при `DATA_HOSTED_IN_RU=true`; голый домен редиректит на `app.`.
- CI: сборка всех Docker-образов, `npm audit`, Dependabot; тесты сайта (`@clubspace/client`)
  в матрице; порог покрытия для мобильного приложения; healthcheck для admin/client/pwa;
  pre-push хук установлен локально; `CHANGELOG.md`; iOS privacy manifest.
- Удаление аккаунта — только с кодом из письма (роль владельца/тренера проверяется до кода).
- Content-Security-Policy (nonce) для админки, сайта и PWA; проверено в браузере без нарушений.
  Цена: страницы админки и сайта рендерятся на каждый запрос.

## Только владелец (по порядку важности)
1. **Юрлицо и данные в РФ.** Оператор сейчас — ИП в Казахстане, а лендинг обещает серверы в РФ.
   Нужны: решение по юрлицу, хостинг в РФ (Selectel/Timeweb/Yandex Cloud), уведомление РКН,
   решение по трансграничной передаче (Expo Push, Sentry, OpenRouter).
2. **Юрист** проверяет оферту, ДПД, политику, согласие (`docs/legal/README.md`, 19 вопросов);
   выбрать один закон (РФ или РК) и один возраст согласия (14 или 16).
3. **Реквизиты продавца** `PLATFORM_SELLER_*` + магазин ЮKassa платформы — без них клубы не могут
   платить картой в проде.
4. **Логотип** → иконка приложения и сплэш. Сейчас стоит **временный** знак (открытая «C» с
   точкой, белым на акценте `#5b58d9`; исходник `apps/mobile/assets/brand/clubspace-mark.svg`):
   `icon.png`, `adaptive-icon.png`, `splash-icon.png`, `favicon.png` в
   `apps/mobile/assets/images/`, PWA-иконки (`scripts/sync-web-assets.mjs`) и `favicon.ico`
   админки и сайта. Настоящий логотип и иконки — по-прежнему за владельцем; заменить те же файлы
   с теми же размерами (иконка 1024×1024 без прозрачности; adaptive — знак в центральных 66%).
5. **Домен, почта поддержки, SMTP** (вход по коду на почту не работает без SMTP).
6. **Сторы:** аккаунты Google Play (закрытый тест 12 тестировщиков × 14 дней), App Store, RuStore;
   Firebase/FCM для push на Android.
7. **CI:** оплатить минуты GitHub Actions или поставить свой раннер — сейчас проверки
   гоняются локально (весь код в `main`).
8. Внешний мониторинг (UptimeRobot на `/readyz`), Sentry в РФ или self-hosted.
9. Решения: включать ли самостоятельную регистрацию клубов; формат экспорта (комментарии
   тренеров без имён — достаточно?); править издание ДПД 2026-11-01 на месте (ок, пока нет
   подписавших клубов).
