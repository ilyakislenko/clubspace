# Демо для показов в клубе

Комплект для живого показа ClubSpace владельцу клуба: MacBook с админкой и 2–3
телефона (тренер, ученик, родитель). На всех экранах — живой клуб
«Академия единоборств «Арсенал»» с историей за три месяца, а не пустые списки.

## Что внутри демо-клуба

- **3 зала** (Ленинский, Южный, Сити), **5 направлений** — БЖЖ, ММА, тайский
  бокс, самбо, ОФП, у каждого руководитель направления.
- **11 групп**, из них детские и подростковые, недельное расписание: занятия
  есть каждый день недели, у тренера `coach@` — тоже каждый день.
- **6 тренеров**, **~125 учеников**, у **6 детей** подтверждённые родители (у
  `parent@` — двое), остальные дети ждут подтверждения родителя; 2 новые заявки
  на вступление.
- **14 недель посещений** с правдоподобным поведением: постоянные,
  «фанаты», новички (часть на пробном занятии), те, кто перестал ходить, и
  ушедшие — список «Кто пропадает» и продления заполнены сами.
- **Тарифы**: «Пробное занятие», «Разовое занятие», «БЖЖ 8», «БЖЖ 12»,
  «БЖЖ + ММА 12», «ММА 12», «Тайский бокс 12», «Самбо 12», «Детские группы 8»,
  «ОФП безлимит», «Безлимит клуб» (месяц и 3 месяца).
- **Абонементы во всех состояниях**: активные, заканчиваются на этой неделе,
  кончились занятия, заморожены (3), заявки на заморозку ждут решения (2) и
  одна отклонённая, не оплачены (долг), истекли без продления; у части
  учеников — два абонемента сразу. Продажи за полгода — на дашборде есть
  выручка и тренд, экспорт выгружает цифры.
- **Ранги**: пояса БЖЖ (взрослые и дети), уровни ММА, пражиады, разряды самбо,
  уровни ОФП; история повышений, прошедшая аттестация с результатами и две
  предстоящие (БЖЖ через 12 дней — с кандидатами и готовностью; детская — через
  19 дней, в ней Миша).
- **Достижения и рейтинг** считаются из посещений — по клубу и по каждому
  направлению.
- **Объявления** (клубные, по направлениям, «абонемент заканчивается»),
  **события** (open mat, семинар, спарринг-день, детский турнир, клубная
  встреча), **персональные тренировки** во всех статусах, **разовые записи**
  в чужую группу.
- **Курсы** по каждому направлению с главами; курс синего пояса БЖЖ закрыт для
  белых поясов. Видео — заглушки: в приложении «в обработке», в админке
  «Видео обрабатывается» (см. «Чего нет»).
- **Тариф платформы**: Pro бесплатно, все модули включены, оферта принята.

Все даты считаются от сегодняшнего дня: после сброса расписание, «сегодня»,
сроки абонементов и аттестаций всегда выглядят актуально.

`DEMO_LOGIN_CODE` (письмо не приходит и не нужно). Код и список аккаунтов
видны администратору платформы в `/platform` → «Демо-клуб».

Код клуба для вступления по QR / коду: **ARSENA77** (если он занят другим
клубом на сервере — актуальный код показан в карточке «Демо-клуб»).

Постоянный код работает **только** при `DEMO_MODE=true`, **только** для этих
адресов и **только** пока аккаунт принадлежит одному демо-клубу. Неверный код
блокирует вход так же, как обычный (5 попыток с адреса, 15 минут). После
`DEMO_MODE=false` демо-сессии на телефонах заканчиваются сами.

## Включить

В `.env` сервера (локально) или `.env.production`:

```sh
DEMO_MODE=true
DEMO_WORKSPACE_KEY=arsenal-demo          # другой ключ — сервер не стартует
DEMO_LOGIN_CODE=<6 случайных цифр>       # LC_ALL=C tr -dc 0-9 </dev/urandom | head -c6
SEED_DEMO_WORKSPACE=true                 # необязательно: создать клуб при старте, если его нет
```

Перезапустите сервер. Клуб создаётся кнопкой «Сбросить демо» (или сам при
старте с `SEED_DEMO_WORKSPACE=true`).

## Сброс перед каждой встречей

- **Консоль платформы**: `/platform` → «Демо-клуб» → «Сбросить демо»
  (только администратор платформы).
- **Терминал на Mac**: `npm run demo:reset` (читает `.env`, нужна та же база,
  что у сервера; сервер должен хотя бы раз стартовать).

Сброс удаляет **только** клуб с ключом `arsenal-demo`, созданный генератором
(`isDemo`), и сгенерированных людей, и строит клуб заново с сегодняшними
датами — меньше чем за пару секунд. Другие клубы и их люди не трогаются;
настоящий клуб с таким ключом сброс не тронет и откажет. Демо-аккаунты
сохраняются, поэтому телефоны остаются залогинены; после сброса потяните экран
вниз (рейтинг из CLI обновится в течение минуты).

Перед встречей:

1. «Сбросить демо» — все прошлые отметки, заморозки и правки исчезнут.
2. На каждом телефоне — потянуть вниз главную, проверить, что клуб «Арсенал».
3. На Mac — войти владельцем, открыть «Обзор».
4. Для показа вступления по QR — держите чистый телефон или свой реальный
   адрес: демо-аккаунты уже в клубе.

## Где показывать: офлайн или сервер

**Сервер (рекомендуется, если в клубе есть интернет).** Демо на боевом
сервере с `DEMO_MODE=true`: телефоны с обычным приложением ClubSpace, админка
по `https://admin.<домен>`. Ничего не нужно поднимать на месте; сбросить можно
с телефона из `/platform`.

**Офлайн: Mac как сервер + раздача с телефона.** Когда в зале нет связи:

1. Дома: `npm run dev:infra`, затем `npm run dev` (база, API, админка,
   Expo) — в `.env` включён демо-режим (см. «Включить»), `npm run demo:reset`.
2. В клубе: включите на одном телефоне режим модема, подключите к нему Mac и
   остальные телефоны. Интернет не нужен — всё ходит внутри этой сети.
3. Узнайте IP Mac в этой сети (`ipconfig getifaddr en0`) и откройте
   приложение на телефонах через Expo Go / dev-сборку, указывающую на
   `http://<IP-Mac>:3000`; админка — `http://localhost:4200` на самом Mac.
4. Перед выходом из дома прогоните `bash scripts/demo-preflight.sh` (проверяет
   API, Metro, MinIO, MailDev, Postgres, Redis).

Офлайн надёжнее связи в подвальном зале, но телефоны должны быть заранее
привязаны к Mac; на сервере проще, но нужен интернет в клубе.

## Чего нет

- **Видео без роликов.** Уроки курсов — заглушки в статусе обработки: в
  приложении они «в обработке», плеер не открывается. Генерация HLS требует
  MinIO/S3 и видео-воркер, поэтому в генератор она не встроена. Чтобы показать
  плеер, загрузите перед встречей 1–2 своих коротких ролика в «Курсы и видео»
  демо-клуба — они пройдут обработку обычным путём (сброс их удалит).
- **Онлайн-оплаты** не настроены (нет магазина ЮKassa у демо-клуба): продажи
  в истории — оплаты на ресепшене.
- Пуш-уведомления сгенерированным ученикам выключены (у них несуществующие
  адреса `@arsenal.demo`).
