# Политика конфиденциальности

Актуальная политика конфиденциальности ClubSpace публикуется на странице
`/legal/privacy` веб-приложения (например, `https://app.<домен>/legal/privacy`).
Исходник страницы: `apps/client/src/app/legal/privacy/page.tsx`.

Инструкция по удалению аккаунта: `/legal/delete-account`
(`apps/client/src/app/legal/delete-account/page.tsx`).

Этот файл намеренно не содержит текста политики, чтобы он не расходился с
опубликованной версией.
